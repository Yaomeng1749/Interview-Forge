# Frontend user journeys

1. As an exam candidate, I can build one or four frozen papers, answer and flag questions, refresh safely, and submit without seeing correctness before submission.
2. As a high-throughput learner, I can start a 20/40/80/160 question rapid drill and see feedback only after each answer.
3. As a bilingual user, I can switch between zh-CN and en-US, retain that choice after reload, and keep an active exam's frozen locale unchanged.
4. As a learner, I can inspect score breakdowns, per-question explanations, learning mastery, the paginated question bank, and due/wrong/bookmarked review queues.
5. As a local-first operator, I can see provider health and change non-secret settings, while provider keys never appear in the browser.
6. As a user facing malformed or unavailable API data, I receive a clear retryable error rather than a broken or misleading screen.
